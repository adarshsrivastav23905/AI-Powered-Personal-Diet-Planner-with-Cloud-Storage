# Project Report

## Abstract

This project builds an AI-assisted personal diet planner using cloud-inspired architecture. The application allows users to create profiles, generate personalized meal recommendations, and manage their saved data with a secure user-scoped design.

## Objectives

- implement a full-stack application
- demonstrate cloud concepts
- provide local simulation of cloud storage and database
- keep the app beginner-friendly and GitHub-ready

## Architecture

The architecture includes frontend, backend, AI logic, database, and simulated storage services. These components work together to provide a complete workflow for personalized diet planning.

## Components

- Frontend: React + Vite
- Backend: Flask REST API
- AI component: rule-based recommendation engine
- Database: SQLite (simulated managed database)
- Storage: local user-scoped storage simulation
- Security: JWT-based authentication

## Key Outcomes

- user registration and login
- diet plan generation based on goals
- cloud storage and file operations
- user-specific data isolation
- responsive dashboard interface
- tested project behavior

## Limitations

- local simulation rather than real cloud deployment
- rule-based AI instead of full LLM integration
- no production-grade medical validation

## Future Scope

- migrate to Firebase/Supabase cloud services
- improve AI recommendations
- add graphs and meal logs
- add notifications and automation
