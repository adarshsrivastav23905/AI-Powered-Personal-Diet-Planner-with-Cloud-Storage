# Viva / Interview Script

## Short Introduction

"This project is an AI-powered personal diet planner with cloud storage functionality. It helps users create profiles, define nutrition goals, and generate personalized meal plans based on their dietary preferences and health targets. The app demonstrates full-stack development, secure authentication, cloud-style storage, and AI-driven recommendation logic."

## Key Points to Explain

1. What is the project about?
   - It is a web application that recommends diet plans based on user profile data.
   - It helps people plan meals according to their goal, such as weight loss, maintenance, or gain.

2. What technologies were used?
   - Frontend: React and Vite
   - Backend: Python Flask
   - Database: SQLite
   - Authentication: JWT
   - Storage: local cloud-storage simulation

3. What cloud concepts are included?
   - User authentication
   - API-based communication
   - Secure and isolated user data
   - Database and storage separation
   - Scalability-ready architecture

4. How does the AI part work?
   - It uses a rule-based recommendation engine that evaluates diet preferences, activity level, goal, calories, and macro needs.
   - The system generates useful suggestions without making medical claims.

5. Why is this project useful?
   - It solves a real-world problem of unhealthy or inconsistent meal planning.
   - It demonstrates how cloud-based apps can personalize user experiences while keeping data organized and safe.

## Closing Statement

"Overall, this project shows my ability to build a complete application from the frontend to the backend, integrate secure user features, and explain cloud-computing concepts through a practical and meaningful real-world use case."
