# Submission Summary

## Project Title
AI-Powered Personal Diet Planner with Cloud Storage

## Objective
The main goal of this project is to build a practical full-stack application that demonstrates how AI, cloud-inspired data storage, secure authentication, and modern web interfaces can work together to help users manage personal nutrition goals.

## Problem Addressed
Many people struggle to plan meals consistently and do not have a structured tool to help them align eating habits with their goals, preferences, and daily needs. This project provides a simple but effective way to generate diet recommendations based on a user profile and health objectives.

## Key Features
- User registration and login
- Profile creation and updates
- Diet plan generation based on activity, goal, and dietary preference
- Storage of plans and user-specific data
- Simulated cloud storage for file handling
- Secure access control and JWT-based authentication
- Responsive modern frontend
- Backend testing and verification

## Cloud Computing Concepts Demonstrated
- Client-server architecture
- API communication between frontend and backend
- Authentication and authorization
- User data isolation
- Structured database usage
- Cloud-like object storage simulation
- Deployment and scalability planning

## Tools and Technologies
- Frontend: React + Vite
- Backend: Python Flask
- Database: SQLite
- AI logic: rule-based recommendation engine
- Authentication: JWT
- Testing: Pytest

## Why This Project Is Strong
This project combines technical implementation with real-world usefulness. It shows the ability to design a complete application, connect multiple layers of the stack, and explain core cloud concepts in a clear and presentable form.

## Final Note
This project is intended for educational and demonstration purposes. It is a professional, presentation-ready application that can be explained confidently in class, in project reviews, and in interviews.
