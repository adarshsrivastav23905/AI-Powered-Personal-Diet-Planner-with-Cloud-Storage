# Final Academic Submission

## Project Title
AI-Powered Personal Diet Planner with Cloud Storage

## Course
Cloud Computing

## Project Summary
This project is a full-stack web application designed to provide personalized diet planning using a cloud-inspired architecture. It combines a modern frontend, an API-based backend, secure user authentication, data storage, and rule-based AI logic to generate meal recommendations based on user goals and preferences.

## Objectives
- Design and develop a full-stack application
- Implement secure user authentication and profile management
- Generate personalized nutrition recommendations
- Simulate cloud database and cloud storage workflows
- Demonstrate real-world application of cloud computing principles
- Deliver a project with documentation, testing, and deployment readiness

## Methodology
The project was built using the following approach:

1. Frontend design with React + Vite
2. Backend implementation with Flask
3. Database creation using SQLite
4. Rule-based AI recommendation engine for diet planning
5. User-specific data isolation and JWT-based access control
6. File upload and storage simulation using a local cloud-style structure
7. Testing using Pytest and verification of frontend build output

## Key Features
- User registration and login
- Profile editing and customization
- Goal-based diet plan generation
- Meal suggestions based on calories and preferences
- Protected routes and user-based access
- Local cloud storage simulation
- Modern UI with dashboard-style presentation

## Cloud Computing Relevance
This project reflects major cloud-computing principles such as scalability, remote data access, API-based services, secure user sessions, cloud storage simulation, and system modularity. It demonstrates how everyday applications can be structured around cloud-ready design patterns even in a local development environment.

## Testing and Validation
The application was validated using automated backend tests and a frontend production build. The project successfully passed its backend test suite and produced a successful Vite build, proving the application remains stable and functional.

## Conclusion
The AI-Powered Personal Diet Planner with Cloud Storage successfully demonstrates the integration of cloud architecture, frontend-backend design, secure data handling, and user-focused AI recommendations. It is a practical, submission-ready academic project that reflects both technical implementation and understanding of modern cloud-based application design.
